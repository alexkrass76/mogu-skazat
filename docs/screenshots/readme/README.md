# Скриншоты для README

Все PNG в этой папке — настоящие снимки работающего приложения «Могу сказать» 0.2.0 (versionCode 3). Сняты 31 октября 2026 года на отдельном эмуляторе Android 15 / API 35, 1920×1440 пикселей, 240 dpi, альбомная ориентация. Изображения не генерировались и не дорисовывались.

Перед съёмкой очищены только данные демонстрационной установки на эмуляторе. Имя и другие сведения о ребёнке не вводились. Настройки и небольшая история созданы действиями в самом приложении: одна просьба из карточек, знакомство с «КОТ», сборка «КОТ» без подсказки и копирование «МОЛОКО». На снимке достижений — результаты этих демонстрационных действий.

Для показа режима по картинке и фраз взрослый режим разрешает уровень 3; для снимка по картинке включён полный русский алфавит, для фразы используется ограниченная клавиатура. Это варианты настройки, а не обязательный маршрут обучения. На эмуляторе отсутствует установленный русский TTS-голос; это не мешает выполнению визуальных упражнений.

В публичную галерею входят только эти специально подготовленные снимки. Старые снимки эмулятора и фотографии/снимки реального планшета остаются исключёнными из Git. Данные реального устройства при подготовке галереи не читались и не менялись.
