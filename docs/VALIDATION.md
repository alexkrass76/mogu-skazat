# Проверки версий

## Базовая проверка 0.1.0

Проверено 31 октября 2026 года. Все команды ниже фактически выполнены.

## Среда

macOS на ARM64; отдельный JDK 17 (Amazon Corretto), Gradle 8.9, Android SDK Platform 35 / Build Tools 34.0.0. Инструменты установлены во временную папку `/tmp/rech-tools`, без изменения системного JDK. Локальный путь SDK в `local.properties` не переносим и не входит в Git. Для постоянной разработки настройте Android Studio по README.

Эмулятор: Android 15 / API 35, `aosp_atd;arm64-v8a`, профиль Pixel C, экран 2560×1800 при 320 dpi (1280×900 dp). Дополнительно проверен портретный размер 1200×1920 при 320 dpi (600×960 dp). У тестового образа ATD по умолчанию выключена графическая отрисовка: для визуальной проверки она была включена свойством `debug.hwui.drawing_enabled=1`, после чего приложение перезапущено. В рабочем APK никаких изменений ради тестового образа нет.

## Итоговый запуск

```sh
./gradlew clean assembleDebug testDebugUnitTest lintDebug connectedDebugAndroidTest
```

Результат: **BUILD SUCCESSFUL**. Установленный APK также успешно запущен отдельно после тестов. Включённый в проект `./gradlew --version` отдельно успешно загрузил Gradle 8.9 с проверкой закреплённой SHA-256.

- 19 модульных тестов: 13 правил адаптации и 6 языковых проверок; ошибок и пропусков нет.
- 7 инструментальных тестов на Android: коммуникация без обучения; ввод буквы и переход к общению; целостность контента; защита кабинета; повторная буква в «ПОМОГИ» и пересоздание Activity; сохранение и удаление профиля через UI; сохранение данных после повторного открытия Room и их очистка вместе с настройками.
- Android Lint: ошибок нет; остаются 11 уведомлений о более новых версиях зависимостей и рекомендация использовать KSP вместо kapt. Текущие версии закреплены и собираются вместе. У kapt есть предупреждение о генерации заглушек с языковым уровнем 1.9; исходный Kotlin-код компилируется Kotlin 2.0.21.
- Упакованный manifest проверен `aapt dump permissions`: нет INTERNET и RECORD_AUDIO. Есть только служебное signature-разрешение AndroidX для неэкспортируемых приёмников, не запрашиваемое у пользователя.
- Все VectorDrawable XML разобраны; контент содержит 23 слова, 22 коммуникационные карточки, 47 упражнений.

При одном промежуточном инкрементальном запуске в `app/build` появились файловые копии с суффиксом «2», вызвавшие конфликт dex-классов. Причина появления копий не установлена. `clean` удалил промежуточные результаты; итоговая чистая сборка и все тесты прошли. В исходниках таких копий нет. Если среда синхронизации документов воспроизведёт конфликт, выполните чистую сборку либо перенесите проект в обычную локальную папку разработки.

## Границы проверки

На тестовом образе нет установленного русского TTS-голоса: проверен доступ к интерфейсу и упражнениям без голоса, а не акустическое качество русской речи. Положительный сценарий звучания на конкретном установленном движке нужно проверить на реальном планшете. Обёртка выбирает русский установленный голос без сетевого требования и показывает родителю статус отсутствия голоса.

Последняя ручная проверка выполнялась с выключенными Wi-Fi и мобильными данными эмулятора. Сборка и установка используют интернет только для инструментов/зависимостей на компьютере; основным функциям приложения сеть не нужна.

Не проводились проверка со специалистом или детьми, измерение образовательной эффективности, полный аудит TalkBack, тесты всех размеров/системных масштабов, длительные нагрузочные испытания истории и полный набор автоматических испытаний на Android 8–14. Дополнительная ручная проверка на реальном планшете Android 13 описана в `DEVICE_TEST.md`. Эти ограничения не подменяются результатом автоматических тестов.

## Версия 0.2.0 — расширенный учебный словарь

Чистая сборка `assembleDebug assembleDebugAndroidTest testDebugUnitTest lintDebug` завершилась успешно. Прошли 19 модульных тестов; ошибок Lint нет, остаются уведомления о новых версиях зависимостей и рекомендация перейти с kapt на KSP.

Восемь инструментальных тестов выполнены напрямую через AndroidJUnitRunner строго на отдельном эмуляторе Android 15, без запуска тестов удаления на реальном планшете. Результат: `OK (8 tests)`, пропусков и сбоев нет. Новый сценарий выбирает тему «Животные», переключает режимы и набирает «ЁЖ» с собственной клавиатуры. Проверка контента подтверждает 50 слов, 216 упражнений, 22 прежние карточки AAC, все четыре учебных режима для каждого слова, уникальные ID, русский алфавит ответов и возможность загрузить все 50 иллюстраций.

Отдельно проверено, что все 47 упражнений версии 0.1.1 сохранили ID, целевой текст, уровень и остальные исходные поля. Поле `learningGroup` добавлено к словам, но схема Room не менялась.

Новые темы визуально просмотрены на эмуляторе: еда, напитки, животные, дом, действия и тело. APK 0.2.0 (versionCode 3) установлен поверх 0.1.1 на ранее подключённый U8 / Android 13. Проверены выбор темы «Животные» и открытие задания «ЁЖ»; данные приложения не очищались, учебный ответ на реальном планшете не вводился. Снимки сохранены локально и исключены из Git.
