# Архитектура

Нативное Android-приложение, один модуль `app`, Kotlin, Jetpack Compose, Material 3. Android 8.0 (API 26) и новее, ориентир — планшет. Зафиксированы AGP 8.7.3, Gradle 8.9, Kotlin/Compose compiler 2.0.21, Compose BOM 2024.12.01. Выбран совместимый воспроизводимый набор версий, а не автоматически обновляемые зависимости.

## Слои

- `domain`: независимые Kotlin-модели контента, настроек и попыток; детерминированная адаптация; небольшой шаблон русских форм фразы. Android API отсутствуют.
- `data`: чтение JSON через `ContentLoader`, Room `AppDatabase` и DAO, Preferences DataStore, оболочка Android TextToSpeech.
- `presentation`: `AppViewModel`, Compose-экраны, компоненты и тема. `StateFlow` собирается с учётом жизненного цикла. Записи и загрузка запускаются через корутины.
- `MainActivity`: создание TTS, корневой экран, навигация и родительский переход.

MVVM без дополнительного DI-фреймворка: зависимости создаются в ViewModel и Activity. Контент загружается на `Dispatchers.IO`; Room и DataStore выполняют дисковую работу асинхронно. Изменения истории и настроек сериализуются `Mutex` в ViewModel. После ошибки записи показывается русское сообщение.

## Поток данных

`assets/content.json → ContentLoader → StateFlow<AppState> → Compose`

`Compose → действие ViewModel → Repository → Room/DataStore → Flow → StateFlow → Compose`

Незавершённый ввод, помощь и результаты текущего упражнения используют `rememberSaveable`: поворот экрана не должен повторно начислять успех. Выход сохраняет частичную попытку, если было взаимодействие. При убийстве процесса незаписанный черновик может потеряться; это ограничение MVP.

## Контент

JSON содержит 50 слов (22 доступны в общении) и 216 упражнений. У слова есть стабильный ID, категория, подпись, ключ иллюстрации, произношение, учебная тема `learningGroup` и форма дополнения после «ХОЧУ»/«ДАЙ». У упражнения — ID, тип, навык, уровень, целевой текст, ссылка на слово и изображение, инструкция, произношение, подсказки и критерий завершения.

Иллюстрации — самостоятельные VectorDrawable в `res/drawable/art_*.xml`. Ключи разрешаются через явную таблицу `illustrationResource`; при неизвестном ключе показывается сообщение об отсутствии картинки, а не изображение другого предмета. Новое изображение требует нового ресурса и строки таблицы. Будущая фотография может быть локальным URI после добавления соответствующего репозитория; работа с фотографиями пока не реализована.

`completion=viewed` означает знакомство без проверки; `exact_text` — совпадение нормализованного текста. Регистр и повторные пробелы не мешают; Ё и Е различаются. Параметры TTS (скорость/включение) берутся из профиля; поле `speech` — текст конкретного упражнения. Подсказки в JSON описывают педагогические варианты; их конкретный показ реализуется экраном по уровню поддержки.

## Локальное хранение

Room: все завершённые/остановленные учебные попытки, созданные сообщения и показы. Храним `exerciseId`, `wordId`, тип, дату, время, завершённость, успех, ошибки, помощь, моделирование. Полный произвольный текст сообщений, звук, диагноз и дата рождения не сохраняются. История сообщений отмечает последнюю выбранную карточку, а не весь состав фразы.

DataStore: необязательное имя/псевдоним, размер, звук, скорость, подсказки, клавиатура, максимум уровня и доступные типы. Один локальный профиль. Схема Room экспортируется в `app/schemas`; миграция потребуется при будущих изменениях.

Удаление очищает таблицу Room и DataStore, затем закрывает кабинет. Между двумя хранилищами общей транзакции нет: если удаление частично не удалось, показывается ошибка и можно повторить. Очистка приложения средствами Android удаляет его приватные файлы целиком. Приложение не обещает криминалистическое стирание с накопителя.

## Озвучивание и приватность

`RussianSpeech` ищет установленный русский голос без требования сети, исключает помеченные неустановленными голоса. Голос и скорость устанавливаются явно. Отсутствие голоса и ошибки воспроизведения видны в кабинете. Голос не скачивается приложением, учебные функции не блокируются. Результат работы зависит от системного движка TTS. `onStop` останавливает речь, `onDestroy` освобождает движок.

Manifest не содержит `INTERNET`, `RECORD_AUDIO` или других разрешений. `queries` для обнаружения TTS-сервиса — видимость пакетов, не сетевое разрешение. Резервное копирование Android отключено. Для защиты от случайного открытия настроек используется случайный арифметический вопрос, без PIN и без заявлений о защите от мотивированного пользователя.

## Расширение контента в 0.2.0

Все 50 слов доступны в EXPLORE, BUILD, COPY и PICTURE; есть 4 задания LETTER и 12 PHRASE. В учебном выборе тема берётся из `learningGroup`, независимо от категорий AAC. Рекомендация ограничивается текущим режимом и темой. Для LETTER темы скрыты; если выбранной темы нет в новом режиме, отображается «Все слова». Дополнительный поиск и сетевой контент не используются. Новые слова помечены `communication=false`, поэтому экран общения сохраняет прежние 22 карточки. База Room и сохранённые ID прежних заданий не менялись.
