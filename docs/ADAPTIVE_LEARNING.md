# Объяснимая адаптация

Реализация: `domain/Models.kt`, объект `AdaptiveLearning`. Нейросети, время ответа, сравнение с другими детьми и медицинские выводы не используются.

## Единица наблюдения

Адаптация считается отдельно для `exerciseId`: сборка «КОТ» не подтверждает самостоятельный набор «КОТ». Попытка содержит дату местного календаря, время записи, тип, успешность, завершённость, количество отметок помощи, число неверных проверок и флаг показа взрослого. Выход после начала ввода или запроса подсказки сохраняется как незавершённая попытка. Пустой экран без взаимодействия не становится попыткой. Частичный ответ при принудительном завершении процесса пока не сохраняется.

Самостоятельный ответ = завершено правильно, нет помощи, нет неверных проверок, это не показ взрослого. Скорость не учитывается. Образец в LETTER/COPY/PHRASE всегда является помощью; ограниченный алфавит и подсветка также являются помощью. Неверная проверка с последующим исправлением даёт успешную, но несамостоятельную попытку.

Счётчик `hints` — **отметки помощи**, а не точное число нажатий: начальный уровень поддержки 1–2 тоже записывается в него. Доля помощи = завершённые учебные попытки с `hints > 0` / все завершённые учебные попытки. Знакомство, коммуникация и показ взрослого исключены из этого знаменателя.

## Правила

Для устойчивых результатов берём последние пять завершённых попыток этого упражнения без показа взрослого, в порядке времени. Для предложения дополнительной помощи отдельно рассматриваем последние два взаимодействия: завершённые попытки либо остановленные попытки с неверными проверками.

| Условие (проверяется сверху вниз) | Предлагаемая помощь | Интервал |
| --- | --- | --- |
| В последних двух взаимодействиях суммарно не менее двух неверных проверок или есть завершённая неуспешная попытка | 2: предложить зрительную опору | 1 день |
| Нет завершённых наблюдений | 1: помощь доступна по запросу | 1 день |
| Не менее четырёх самостоятельных результатов и не менее трёх различных дат самостоятельных результатов | 0: можно убрать автоматическую подсветку | 3 дня |
| Иначе | 1: знакомое задание с доступной помощью | 1 день |

При рекомендации 2 в следующей попытке показывается следующая буква, если родитель разрешил подсказки. Полный образец открывается дополнительным нажатием. Рекомендация 0 убирает автоматическую подсветку, но не скрывает кнопку добровольной помощи и не меняет учебную задачу с обязательным образцом. Уровень и типы упражнений меняет только взрослый. Алфавит также выбирает взрослый; автоматического переключения на полную клавиатуру нет.

Эти числовые пороги и календарные интервалы — проектные гипотезы. Научное исследование не валидировало их для этого продукта.

## Выбор задания

Отбираются разрешённые взрослым типы и уровни. Для каждой карточки определяется последняя завершённая попытка без показа взрослого. Новые задания имеют первый приоритет; остальные сортируются по дате следующего предложения: последняя дата + интервал. При равенстве — стабильный порядок идентификаторов. Выбор детерминирован при одинаковых данных.

Дата предложения не запрещает заниматься раньше. Рекомендация — удобный вход, а не обязательная очередь. «Дальше» предлагает другое упражнение того же типа в пределах разрешённых настроек; если другого нет, возвращает к выбору. Взрослый может выключить предложения и адаптацию. «Общаться» доступно из задания и не участвует в этих ограничениях.

В MVP `EXPLORE` записывается как знакомство/моделирование, не освоение; поэтому такие упражнения не получают интервального статуса. Завершённая неуспешная попытка предусмотрена моделью данных, но текущий UI сохраняет неверные проверки внутри попытки до успеха либо выхода. Незавершённые попытки не подтверждают освоение. Если перед выходом были неверные проверки, они могут дать предложение дополнительной помощи; простой выход без неверных проверок не меняет поддержку.

## Что алгоритм не устанавливает

«Устойчивый ответ» означает только достижение порога в конкретном упражнении. Это не доказательство узнавания слова в другом шрифте, понимания прочитанного, развития интеллекта, улучшения устной речи или самостоятельного общения вне приложения. Изменение часов устройства влияет на календарную историю. Длинные серии в один день не дают уменьшения помощи.
