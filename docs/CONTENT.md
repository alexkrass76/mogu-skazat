# Контент и авторские изображения

Словарь и упражнения находятся в `app/src/main/assets/content.json`, независимо от экранов. Русские подписи интерфейса определены в Compose-компонентах; перенос на другой язык не входит в MVP.

## Поля слова

| Поле | Значение |
| --- | --- |
| id | Стабильный технический идентификатор |
| text | Русская подпись прописными буквами |
| category | Категория общения; учебные слова могут иметь другие категории |
| learningGroup | Тема в учебном выборе; если поле отсутствует, используется category |
| communication | Доступность в модуле общения; учебные слова могут быть исключены |
| image | Ключ VectorDrawable в таблице `Illustration` |
| spoken | Текст озвучивания карточки |
| phraseForm | Форма для простого шаблона дополнения после «ХОЧУ»/«ДАЙ» |

## Поля упражнения

`id`, `type`, `skill`, `level` (1–3), `text` (целевой ответ), `wordId`, `image`, `instruction`, `speech`, `hints` и `completion`.

Типы: EXPLORE — знакомство, BUILD — сборка, LETTER — отдельная графема, COPY — набор по образцу, PICTURE — по изображению, PHRASE — фраза по образцу. Критерии: `viewed` — нажать продолжение без проверки знания; `exact_text` — точный нормализованный ответ. Множество букв для сборки выводится из целевого текста, включая отдельные фишки для повторных букв. Полная клавиатура всегда включает 33 буквы.

Изменяя контент, сохраняйте прежние ID для сохранности связей истории, согласуйте текст со взрослым и иллюстрацией и запускайте тесты целостности. Уровень и наличие типа должны соответствовать настройкам. В текущей версии неизвестный тип или отсутствующая ссылка на слово приводят к понятному сообщению о невозможности открыть упражнения.

## Происхождение изображений

Все `art_*.xml` и `ic_app.xml` созданы непосредственно для этого проекта из простых векторных фигур. Сторонние библиотеки пиктограмм, изображения из поиска, эмодзи, фотографии, звуковые записи и скачанные шрифты не использованы. У каждого изображения есть редактируемый XML-исходник; проект не зависит от внешнего сервиса изображений.

Рисунок обозначает предложенное значение, но не гарантирует узнавание ребёнком. Символы абстрактных слов показываются в ситуации взрослым. «МАК» изображён как цветок и включён только в учебные упражнения (`communication=false`), без размещения в категории еды. Это позволяет сохранить пример короткого слова, не предлагая несоответствующую картинку для бытовой просьбы.

## Набор версии 0.2.0

50 слов, 50 авторских рисунков, 216 упражнений:

| Режим | Количество |
| --- | --- |
| Знакомство | 50 |
| Сборка из букв | 50 |
| Набор по образцу | 50 |
| Набор по картинке | 50 |
| Одна буква | 4 |
| Фраза по образцу | 12 |

Добавлены 27 слов: СУП, СЫР, ХЛЕБ, ЧАЙ, МОЛОКО, ГРУША, СЛИВА, РЫБА, УТКА, ГУСЬ, МЫШЬ, ЗАЯЦ, ЛИСА, КАША, СТОЛ, СТУЛ, ЧАШКА, ЛОЖКА, КНИГА, КУБИК, СПАТЬ, ИДТИ, МЫТЬ, СТОП, РУКА, РОТ, ЁЖ.

Кроме прежних фраз добавлены: «ДАЙ КНИГУ», «ДАЙ ЛОЖКУ», «ДАЙ КУБИК», «ХОЧУ СПАТЬ», «ХОЧУ ЕСТЬ», «ХОЧУ СОК», «ХОЧУ ЯБЛОКО», «ЕЩЁ ЧАЯ», «НЕ ХОЧУ». Словоформы во фразах заданы явно: это не результат общего морфологического анализа.

Темы: еда, напитки, животные, игрушки, дом, действия, общение, тело, растения. Это организация выбора по смыслу, а не шкала способностей или фонетическая последовательность. Уровни сохраняют смысл режимов: знакомство и буква — 1, сборка и копирование — 2, картинка и фраза — 3. Длина слова сама по себе не определяет уровень развития ребёнка.

Слова учебного набора могут обозначать разные вещи одной картинкой в повседневной речи: «СПАТЬ»/«ОТДЫХ», «ЧАЙ»/«ЧАШКА». Рисунки специально различаются (спящий человек, кровать, чашка с напитком и пустая чашка), но взрослый всё равно показывает значение в ситуации. «ЁЖ» и «МЫШЬ» позволяют встретить Ё и Ь в осмысленном слове без предъявления названия буквы как фонемы.

Все прежние 47 упражнений сохранены без изменения ID, целевого текста и уровня. Для прежних слов добавлены недостающие режимы; история старых попыток остаётся связанной с теми же заданиями. Новые слова не добавляются автоматически в AAC-раскладку.
